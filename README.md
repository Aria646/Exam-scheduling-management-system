# Exam Scheduling and Management System

A Java application project for modelling and managing examination-related data, including students, subjects, units, venues and sessions.

## Highlights
- Structured model layer for students, subjects, units, venues, desks and sessions
- Controller and view components for application interaction
- File-selection and dialog utilities
- Unit tests covering key model classes and behaviours
- Demonstrates object-oriented programming, modular architecture and software testing

## Technologies
Java, OOP, MVC-style architecture, unit testing
